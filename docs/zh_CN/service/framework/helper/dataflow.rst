DataFlow Helper
===============

:link_to_translation:`en:[English]`

- 公共头文件： ``#include "brookesia/service_helper/framework/dataflow.hpp"``

概述
----

DataFlow helper 提供类型安全的控制面接口，用于 provider 发现、输出发现、操作归属、生命周期管理和源路由。原生视频帧与音频缓冲区访问仍由类型安全的 C++ 操作接口负责。
